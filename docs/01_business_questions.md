# Q1–Q4 业务问题定义

> **第6周周一任务**｜要求：每个问题都写清「要什么数据 / 用什么指标 / 要什么形式的结论」。
> 判断标准：**如果一个问题没法用"数值 + 对比基准"回答，它就不是业务问题，是感想。**
> 场景设定（写下来，面试要用）：我是「知识区 · 职场垂类」的内容运营/数据分析师，每周要决定下周发什么。

## 场景与角色

- 我的角色：一个稍微懂点职场生存之道、摸爬滚打的小职员，但领悟能力不错
- 我服务的业务目标（如涨粉 / 播放量 / 互动率 / 商单转化）：涨粉丝3000和5w播放量，以此转化为商机（我对这个不是很了解，我没当过主播）
- 我的决策周期（每周/每双周）：每周，虽然工作量大但是要跟上时事
- 我现在做决策的方式（拍脑袋？看热榜？）：根据热榜思考决策。但要有长远目光。

## Q1 · 哪些细分选题供过于求 / 供不应求？

| 项 | 内容 |
|---|---|
| 需要什么数据 | 视频的：分区/标签/标题关键词 + 播放 + 互动 + 发布时间；**要有"供给量"和"需求量"两个维度** |
| 用什么指标 | 供给量＝视频数量；需求量＝播放量中位数 |
| 对比基准 | 分区平均 |
| 结论形式 | 供需矩阵（横轴供给量、纵轴播放中位数） |
| 潜在陷阱 | 高播放可能只因为该细分头部UP主多 → 需要做这个大类下另外的小分类，按 UP 主粉丝量分档后再比。或者避开这个细分类另辟新径 |

## Q2 · 什么内容组合（时长/时段/标题/UP主体量）能拿到高播放与高互动？

| 项 | 内容 |
|---|---|
| 需要什么数据 | 时长、发布时间、标题文本特征、UP主粉丝量、分区 |
| 因变量（要解释的指标） | 播放量中位数 |
| 自变量与分桶 | 时长<3 / 3–8 / 8–15 / 15–30 / >30 分钟、时段周五/周六18点左右、标题含数字、职场经验的字眼 |
| **必须控制的变量** |我要控制分区和UP主粉丝量分档。因为粉丝量大的 UP 主播放天然更高，如果不分档，我比较的其实是"UP主体量"而不是"时长/时段"|
| 结论形式 | 对比表和可执行的建议 |

## Q3 · 观众在弹幕与评论里要什么、骂什么？

> 实测提醒（2026-10-11）：匿名拿不到评论翻页（只回 3 条预览）→ **弹幕是主数据源**
> （`dm/list.so`，无需登录、单视频数百条），评论降为"事后观点"的对照样本。

| 项 | 内容 |
|---|---|
| 需要什么数据 | 弹幕内容 + 出现时间（`send_time_sec`）+ 评论内容与点赞数 + 所属视频（分区/时长/播放） |
| 用什么方法 | 分词（jieba）→ 词频/去重刷屏 → 主题聚类 → 情感分类；**情感怎么定义正/中/负？**（待填） |
| 两路对照 | 弹幕（即时情绪）vs 评论（事后评价）是否一致？不一致的地方说明什么？（待填） |
| 样本与标注 | 弹幕/评论各标多少条？（建议各 250）标注规则？（待填） |
| 结论形式 | （待填：需求词表 + 多少条候选选题池？谁会用？） |
| 潜在陷阱 | 弹幕的刷屏重复、玩梗、极短文本会污染词频 → 怎么处理？（待填：按文本去重 + 保留次数作权重？） |
| 潜在陷阱 2 | 情绪 ≠ 内容质量（玩梗/吵架）→ 报告里怎么说明？（待填） |
